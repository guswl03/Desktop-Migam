## 프로젝트 안내

Desktop Migam은 같은 감자 캐릭터와 핵심 경험을 Windows와 macOS 환경에 맞게 각각 구현합니다. 설치 방법, 최신 코드, 이슈와 릴리스 파일은 운영체제별 저장소에서 관리합니다.

- Windows 관련 문의와 개발: [Desktop-Migam-Window](https://github.com/guswl03/Desktop-Migam-Window)
- macOS 관련 문의와 개발: [Desktop-Migam-Mac](https://github.com/ariha1982/Desktop-Migam-Mac)
