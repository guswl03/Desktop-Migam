# Desktop Migam 소개 웹사이트 설계

## 목표

Windows와 macOS로 나뉜 Desktop Migam을 하나의 제품으로 소개하고, 방문자가 프로그램의 성격과 핵심 기능을 이해한 뒤 자신의 운영체제용 저장소로 이동하게 한다. 사이트는 `Desktop-Migam` 저장소의 GitHub Pages에서 공개한다.

## 사용자 흐름

1. 첫 화면에서 움직이는 감자 캐릭터와 핵심 문구로 제품을 인식한다.
2. 스크롤하며 집중 타이머, 투두리스트, GAMCHA 도감, 사진 배달, 시스템 반응 기능을 확인한다.
3. 실제 앱을 연상시키는 말풍선과 디버거 창 연출로 사용 분위기를 파악한다.
4. 마지막 플랫폼 선택 영역에서 Windows 또는 macOS 저장소로 이동한다.

## 시각 방향

- 현재 앱의 WinDbg/데스크톱 유틸리티 분위기를 유지하되 웹에서는 더 읽기 쉽게 정돈한다.
- 배경은 밝은 작업 화면과 짙은 디버거 패널을 교차 사용한다.
- 파랑은 시스템 UI, 노랑은 티켓, 분홍·보라·초록은 GAMCHA 강조색으로 사용한다.
- 감자 캐릭터는 기존 프로젝트 자산을 재사용하며 첫 화면에서 걷기 또는 대기 애니메이션을 재생한다.
- 장식보다 프로그램 기능과 운영체제 선택을 우선한다.

## 페이지 구성

### 상단 내비게이션

- `MIGAM DESKTOP` 워드마크
- 기능, GAMCHA, 플랫폼 영역으로 이동하는 앵커 링크
- 우측 `다운로드 선택` 버튼

### 히어로

- 문구: `집중할 때도, 쉴 때도 곁에 있는 데스크톱 펫`
- 짧은 제품 설명과 `기능 둘러보기`, `운영체제 선택` 버튼
- 감자 캐릭터, 타이머 말풍선, 티켓 표시를 조합한 앱 미리보기
- 캐릭터는 화면 안에서 짧게 걷고 멈추며, 모션 감소 설정에서는 정지한다.

### 기능 소개

- 집중 타이머와 휴식 전환
- 오늘 할 일과 집중 대상 연결
- 집중 완료 티켓과 156종 코스튬 도감
- 사진 배달과 시스템 사용량 반응
- 안전한 집중 보호와 긴급 중지

각 기능은 실제 UI를 단순화한 카드로 표현하고 과도한 설명은 피한다.

### GAMCHA 강조 영역

- 다채로운 `gamcha!` 타이포그래피
- 티켓 획득에서 코스튬 수집까지의 짧은 흐름
- 색종이와 빛 효과는 CSS로 구현하고 모션 감소 설정을 존중한다.

### 플랫폼 선택

- Windows 카드: `guswl03/Desktop-Migam-Window`
- macOS 카드: `ariha1982/Desktop-Migam-Mac`
- 각 카드에 지원 환경, 저장소 이동 버튼, 설치파일은 Releases에서 제공된다는 안내를 표시한다.
- 아직 릴리스가 없을 때 깨진 직접 다운로드 링크를 만들지 않는다.

### 푸터

- 두 저장소 링크와 GitHub 프로젝트 안내
- 로컬 저장·개인정보 보호에 대한 한 문장 설명

## 기술 구조

- Vite와 TypeScript 기반 단일 정적 페이지
- 서버, 계정, 데이터베이스 없이 동작
- CSS 반응형 레이아웃과 최소한의 TypeScript 상호작용 사용
- 기존 캐릭터 이미지는 저장소 안의 웹 최적화 자산으로 포함
- GitHub Actions가 `main` 변경 시 빌드 결과를 GitHub Pages에 배포
- 저장소 프로젝트 페이지 경로에서도 자산이 깨지지 않도록 상대 base 경로를 사용

## 접근성과 반응형

- 모든 링크와 버튼은 키보드로 접근 가능하게 한다.
- 명확한 포커스 표시, 충분한 색 대비, 의미 있는 대체 텍스트를 제공한다.
- `prefers-reduced-motion`에서는 걷기·색종이·부유 애니메이션을 제거한다.
- 작은 화면에서는 기능 카드와 플랫폼 카드를 한 열로 배치한다.

## 오류와 경계 조건

- 외부 저장소 링크는 새 탭으로 열고 안전한 `rel` 값을 사용한다.
- GitHub Pages의 하위 경로 배포에서도 새로고침과 정적 자산 로딩이 정상이어야 한다.
- JavaScript가 늦게 실행되어도 제품 소개와 플랫폼 링크는 HTML로 즉시 표시한다.

## 검증 기준

- TypeScript 검사와 프로덕션 빌드가 성공한다.
- 주요 링크가 정확한 Windows/macOS 저장소를 가리킨다.
- 데스크톱과 모바일 너비에서 가로 스크롤이 발생하지 않는다.
- 모션 감소 환경에서 핵심 콘텐츠가 사라지지 않는다.
- GitHub Pages 워크플로 구문과 빌드 산출물 경로가 올바르다.

## 범위 제외

- 회원가입, 클라우드 동기화, 결제, 분석 도구
- 운영체제별 코드를 대표 저장소로 합치는 작업
- 릴리스가 없는 플랫폼의 가짜 다운로드 파일 또는 링크
